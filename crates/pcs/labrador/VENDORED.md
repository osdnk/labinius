# Vendored LaBRADOR

This directory is an in-tree copy of a fork of the LaBRADOR reference
implementation (https://github.com/lattice-dogs/labrador, upstream commit
`8b6626b`), with local changes made here directly. `crates/pcs/build.rs`
builds `liblabrador.a` from it with `LOGQ=48`. See `LICENSE` for the library's
licence.
